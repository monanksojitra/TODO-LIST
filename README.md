# Simple Todo List Project

This is a simple todo list project created using only HTML. It allows users to add tasks, mark them as completed, and delete tasks from the list.

## Features
- Add new tasks by typing in the input field and pressing the "Add Task" button
- Mark tasks as completed by clicking on the checkbox next to the task
- Delete tasks by clicking on the "Delete" button next to the task

## Getting Started
1. Clone the repository
2. Open the `index.html` file in your web browser
3. Start adding tasks to the todo list
